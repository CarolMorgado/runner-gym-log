# Training Plan — 4 weeks

The full program the app is built on. Sets × reps; "A1 + A2" = superset (rest only after A2). Every exercise links to YouTube form videos.

## Session structure (60–80 min, max 90)

1. Warm-up + mobility — 10 min
2. Plyometrics / tendon work — 10 min, done fresh
3. Main block — supersets or circuits
4. Core / finisher
5. Cool-down mobility — 5 min

Pick weights so you finish each set with about 2 reps left in the tank.

## Safety

- Pain above 3/10, or pain that gets worse during a set: stop and swap for an easier exercise.
- Plyometrics come early in the session, with clean landings.
- Hard running weeks: 2 sets per exercise and skip the plyo block.
- Existing injury: check the plan with a physiotherapist first.
